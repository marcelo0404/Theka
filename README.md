# 📚 Theka - Acervo Virtual de Livros

Desenvolvimento do frontend para a plataforma **Theka**, um acervo virtual de biblioteca integrado a uma API dinâmica. Este projeto faz parte da etapa final do processo seletivo para Trainee de Desenvolvimento Front-end da **EJECT**.


---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes tecnologias e ecossistemas:
* **React**  
* **TypeScript**  
* **CSS**  
* **Git & GitHub** 

---

## 💻 Telas e Funcionalidades Desenvolvidas

Seguindo estritamente o escopo proposto pelo desafio:

### 🔐 Autenticação
* **Página de Login & Cadastro:** Formulários validados para entrada e registro de novos usuários no sistema.

### 🏠 Home
* **Banner Principal:** Espaço de propaganda da biblioteca.
* **Destaques do Mês:** Seção dedicada aos livros em evidência.
* **Estatísticas:** Métricas de desempenho e dados da empresa.

### 📖 Acervo da Biblioteca
* **Listagem em Grid:** Exibição dinâmica dos livros consumidos via API.
* **Busca e Filtros:** Barra de pesquisa funcional com filtros por categoria e editora.
* **Modal de Detalhes:** Visualização completa das informações do livro (capa, título, autor, ano, páginas e resumo).
* **Operações CRUD:**
    * Cadastrar novo livro (Botão de abrir modal + Salvar).
    * Editar informações (Modal de edição + Salvar).
    * Excluir livro do acervo.

### 🏢 Institucional e Contato
* **Página Sobre Nós:** Apresentação da história, valores e equipe.
* **Página de Contato:** Formulário funcional com botão de envio e integração de mapa.

## ⚙️ Como Executar o Projeto

Siga os passos abaixo para rodar a aplicação localmente:

### Pré-requisitos
Certifique-se de ter o [Node.js](https://nodejs.org/) instalado em sua máquina.

### Passo a Passo
1. **Clone o repositório:**
   ```bash
   git clone [https://github.com/marcelo0404/Theka]

2. **Entre na pasta do projeto:**
   ```bash
   cd THEKA

3. **Instale as dependências**      
    ```bash
    npm install

4. **Execute**
    ```bash
    npm rum dev    

5. **Abra http://localhost:5173 no seu navegador.**
